## Project overview

This Senior Design Project focuses on building an inquiry-based learning
platform that turns textbook material into more interactive study modules. The
goal is to support learning through generated questions, explanations, and a
workflow that helps students engage with material more actively.

## What we built

- A web platform centered on educational content and interactive study flow
- LLM-supported question and explanation generation
- Backend workflow automation for processing and organizing learning material
- A system architecture using Go, Docker, and frontend styling with Tailwind CSS

## Key technical decisions

One of the important design goals was to connect educational material with a
workflow that feels structured rather than purely chat-based. That means the
system has to do more than generate text: it has to organize content into a
usable learning process.

Another key decision was to treat LLM output as part of a larger application
pipeline, rather than the entire product. That makes backend orchestration and
system design just as important as the model-driven features.

## Challenges and lessons learned

This project is valuable because it combines multiple concerns at once:
educational product thinking, backend workflow design, and applied AI
engineering. It also raises practical questions about how generated content
should be structured, reviewed, and presented to users meaningfully.
