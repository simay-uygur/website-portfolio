## Project overview

This homework combined machine learning theory with a practical
implementation task. The assignment covered Bayesian inference, MLE and MAP
estimation, and a full Naive Bayes classifier using the Bernoulli document
model.

The final classification task used a Hogwarts-themed multi-class dataset,
where students had to be assigned to houses such as Gryffindor, Hufflepuff,
Ravenclaw, and Slytherin based on phrase-level features.

## What I worked on

- Probability reasoning and derivations for a prize-selection problem
- Deriving MLE and MAP estimators for a Gaussian model with known variance
- Implementing a Bernoulli Naive Bayes classifier from scratch
- Evaluating the classifier with accuracy and confusion matrices
- Interpreting informative features and analyzing class-specific predictions

## Key technical ideas

One major part of the homework was understanding how probabilistic modeling
connects theory and implementation. The Bayesian inference section required
deriving posterior and MAP expressions explicitly, while the classifier section
required translating those ideas into a working learning system.

Another important aspect was implementing the classifier without using
high-level machine learning libraries. That made the parameter estimation,
prediction flow, and feature interpretation much more explicit.

## Challenges and lessons learned

This homework was useful because it connected mathematical derivation with an
end-to-end classification pipeline. It reinforced how prior assumptions affect
estimates, how simple probabilistic models can still be effective, and how
feature-level analysis helps interpret a model’s behavior.
