## Project overview

This project focused on implementing a UART communication system at the
hardware level on FPGA. It combined protocol-level thinking with digital design
and practical system integration.

## What I built

- A UART communication design on FPGA
- FIFO-based buffering for data handling
- Parity handling and protocol-related control logic
- Display integration for observing and testing behavior

## Key technical decisions

The project required careful thinking about the interaction between modules,
timing-sensitive behavior, and how to structure the design so that debugging
was still manageable at the hardware level.

## Challenges and lessons learned

This work strengthened my understanding of low-level system design and made the
relationship between protocol behavior, buffering, and implementation details
much more concrete.
