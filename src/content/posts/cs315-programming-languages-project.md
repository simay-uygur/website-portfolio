## Project overview

This project focused on building the front end of a custom programming
language. The main goal was to understand how source code moves through lexical
analysis, parsing, and structured error handling.

## What I built

- A lexer using Flex/Lex
- A parser using Bison/Yacc
- Core language features for a custom language design
- Automated testing and build support through GNU Make

## Key technical decisions

The implementation required a clear mapping between the language grammar and
the parser structure. Small grammar changes could have large effects on parser
behavior, so the design needed to stay consistent and easy to reason about.

## Challenges and lessons learned

This project made parsing theory much more practical. It also improved my
discipline around debugging structured input, understanding parser failures,
and thinking more carefully about language rules.
