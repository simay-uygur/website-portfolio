## Project overview

This project was a full-stack system for managing teaching assistant workloads,
proctoring assignments, leave requests, and reporting needs in an academic
setting. The aim was to support different user roles with a structured and
usable workflow.

## What I built

- Backend functionality with Spring Boot
- Frontend work with React
- Database deployment and project infrastructure using an AWS EC2 instance
- Role-based access control for different types of users
- A data-backed system for handling requests, assignments, and administrative views

## Key technical decisions

A major concern in this project was separating responsibilities clearly between
roles and between layers of the system. That affected how we designed the
Spring Boot backend, the React frontend, and the database setup running on AWS
EC2.

## Challenges and lessons learned

The project strengthened my understanding of full-stack coordination: backend
and frontend integration, database hosting concerns, shared assumptions about
data, and how role-based systems create extra edge cases around permissions and
user experience.
